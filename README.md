## 📝 Project Description

The **Employee Task Tracker** is a web-based application designed to manage and monitor tasks assigned to employees within an organization.  
The system provides role-based access for **Admin**, **Manager**, **Leader**, and **Employee**, enabling structured workflows for task assignment, status updates, deadline tracking, and team performance monitoring.  
It replaces traditional methods like paper notes, emails, and spreadsheets with a centralized platform, making task management more **organized, transparent, and efficient**.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS (responsive dark theme UI)  
- **Backend:** Python (Flask), Flask Blueprints  
- **Database:** SQLite (with SQLAlchemy ORM)  
- **Authentication:** Flask session, Werkzeug password hashing  
- **Version Control:** Git & GitHub  
- **Tools:** Visual Studio Code
